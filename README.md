# geekAluraShop
Proyecto que busca solucionar el segundo challenge de Oracle One Alura
# Ejecucion
El proyecto se ejecuta en un json local con una las dependencias previas instaladas
"npm install" en la linea de comandos y para ejecutar el servidor "npx json-server --watch db.json --port 5500"
